# A34 — Tools and worker actions register themselves: each viewport/tools/*_tool.gd declares a ...

Status: Active | Subject: Architecture | Principles: G12 | Date: 2026-11-22
Replaces / replaced by: —
Where in the code: viewport/tool_registry.gd; worker/model.py action_mixins

Tools and worker actions register themselves: each viewport/tools/*_tool.gd declares a TOOL constant (id, label, tip, key, order) and main.gd builds the tools, toolbar, Tools menu and keys from them (viewport/tool_registry.gd); the worker's op types come from op_<type> methods and its action classes (*Actions) are found by file. A new tool or kind of action is one new file.

Why: Your approval of the process review, 2026-11-22: every new tool edited main.gd, keys.gd and model.py, so shape tools couldn't run in parallel. Checked in the exported app (build_app.sh runs the tool check).
