# I58 — Line tool: key L.

Status: Active | Subject: Drawing tools | Principles: G03 | Date: 2026-11-22

Where in the code: viewport/tools/line_tool.gd (T82); quick test viewport/tests/quick/line.gd

Line tool: key L. Click-click chain: each click ends one line and starts the next from that point; Esc ends the chain, and clicking the start point closes the loop into a face. A typed length sets the current line's length along the direction you're pointing. Press-drag-release (I43's 6 px / HOLD_MS rule) draws a single line.
