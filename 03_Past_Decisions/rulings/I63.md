Preferences are a JSON file for now (a Mac window later, T111): user://preferences.json holds the default units (I62) and a 'tuning' section with the input-feel tunables (SNAP_PX, EDGE_PX, INFER_DEG, RELEASE_DEG, DRAG_PX, HOLD_MS, TRACKPAD_PX, ZOOM_STEP, GRID); a missing key keeps the built-in value. Shop Sketch > Preferences… (⌘,) opens it in the text editor, writing it with the current values if it isn't there; saving it applies the change at once. A file or value that can't be used keeps the last good values and the status bar says why. Tests never read it.

Why: William, 2026-11-22: units plus the feel tunables, live, so the feel test on real hardware (Q4) can tune while drawing.
