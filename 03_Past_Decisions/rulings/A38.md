When Shop Sketch takes in a FreeCAD edit (opening a file changed outside it, or reloading an outside save), the worker writes <model>.floor.FCStd beside the model: the file as it was then, with the undo floor. A rebuild (undo past FreeCAD's 20 steps, or below what the file held on opening) starts from that copy and applies the actions after the floor, so the FreeCAD edit is kept. A model never edited in FreeCAD has no floor copy.

Why: Your call, 2026-11-22: beside the model, so it survives a restart.
