# I11 — Tools act on what you can see when you start.

Status: Active | Subject: Drawing tools | Principles: G01 | Date: 2026-11-20
Replaces / replaced by: —
Where in the code: main.gd _rect_drag(), _push_drag()

Tools act on what you can see when you start. Once started, an operation is locked to its face/axis, so rotating the view mid-operation doesn't change its target.

Why: You can only start on a visible face. Tested: orbiting away mid-rectangle and mid-push still finishes on the original face.
