# A25 — Opening a Shop Sketch file adopts its journal, so undo works across sessions.

Status: Active | Subject: Files, saving and undo | Principles: G02, G09 | Date: 2026-11-20
Replaces / replaced by: —
Where in the code: replay.py _open_existing(); main.gd _on_open(), undo_floor

Opening a Shop Sketch file adopts its journal, so undo works across sessions. If the file was changed in FreeCAD since Shop Sketch saved it, undo stops at that point instead of losing the change (merging is stage 2). The worker reloads a file that was replaced on disk.

Why: No silent loss of FreeCAD-side work. Files Shop Sketch didn't make open as-is; adopting their solids as boards is stage 3 (Q17).
