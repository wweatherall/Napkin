# I66 — Typing an array count (Nx, xN, *N, /N) during a Move previews the array live before cli...

Status: Active | Subject: Move, copies and arrays | Principles: G03, G06, G13 | Date: 2026-11-24
Replaces / replaced by: Extends I14, I25
Where in the code: viewport/tools/move_tool.gd

Typing an array count (Nx, xN, *N, /N) during a Move previews the array live before clicking (enabling copy mode if not yet on) and commits with that count on click or typed distance; after clicking, before any other action, typing a count or distance still amends the array.

Why: William, 2026-11-24: typing x8 should preview the array before clicking and also work after clicking before any other action.
