# I67 — A document with no units explicitly set yet (new model or pre-T66 model without saved S...

Status: Active | Subject: Measurements | Principles: G03, G06 | Date: 2026-11-24
Replaces / replaced by: Refines I57, I59, I62
Where in the code: viewport/measure_box.gd, viewport/units.gd

A document with no units explicitly set yet (new model or pre-T66 model without saved ShopSketchUnits) starts in the previous/preference units (I62), and adopts the unit of the first typed length that includes an explicit unit (saving it to the .FCStd and remembering it as last used); bare numbers keep the previous settings.

Why: William, 2026-11-24: document units should reflect the first typed length if unset, else previous settings.
