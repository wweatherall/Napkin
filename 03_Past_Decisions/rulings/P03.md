# P03 — Recordings use --true-latency: each FreeCAD reply is held until the video clock has run...

Status: Active | Subject: Process | Principles: G11 | Date: 2026-11-20
Replaces / replaced by: —
Where in the code: main.gd true_latency; --heavytest

Recordings use --true-latency: each FreeCAD reply is held until the video clock has run FreeCAD's real measured time, so videos show true waits with smooth frames.

Why: This server renders in software (~4 fps live), which would make Shop Sketch look choppy; the movie writer alone compressed waits about 3×.
