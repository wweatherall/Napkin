Agents work in parallel by files, not topics, as P11 said (each job lists its Touches and stays within one session), and may share a file by function: a Touches entry can name, in backticks after the file, the functions or constants it changes (viewport/main.gd (`redo`, `_ask_outside`)); two jobs naming the same file overlap only if their names meet. A file named without names is the whole file. The integrator resolves any textual clash at merge; the gate catches the rest.

Why: William, 2026-11-22: six queued jobs touched different parts of main.gd and waited on each other; teams rely on git merging separate hunks and tests, not file locks.
