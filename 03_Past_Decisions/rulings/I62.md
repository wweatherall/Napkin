# I62 — A model with no units saved in it (made before T66, or its saved value unreadable) open...

Status: Active | Subject: Measurements | Principles: G03, G06 | Date: 2026-11-22
Replaces / replaced by: Refines I57
Where in the code: Not built: H052 (worker/session.py, viewport units)

A model with no units saved in it (made before T66, or its saved value unreadable) opens in the default units the user has set (once Preferences exist, T111), else the last units used, as a new model does. It is then saved with them.

Why: William, 2026-11-22 (H052's brief): old models shouldn't jump to a fixed default.
