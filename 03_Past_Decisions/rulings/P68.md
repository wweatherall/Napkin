A Work list item is a to-do with a life story: Open -> Picked up (when the integrator takes it from the to-do list) -> On the board (every job written from it linked on the item, with each one's progress) -> Done by itself when the last linked job merges; no Completes line needed. More work found later is a new item, or the item is reopened.

Why: William, 2026-11-26: some to-dos become several jobs; register picking one up, link each job to it, mark it done when the last finishes.
