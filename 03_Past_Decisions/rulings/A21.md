# A21 — The FreeCAD file (.FCStd) is the model.

Status: Active | Subject: Files, saving and undo | Principles: G02 | Date: 2026-11-20
Replaces / replaced by: Replaces A01
Where in the code: worker/replay.py Session, Model

The FreeCAD file (.FCStd) is the model. Every Shop Sketch action becomes ordinary FreeCAD features in it, saved as you go. Shop Sketch and FreeCAD are two views of the same actions, like a GUI over a command line. The live draft-then-catch-up loop (A01's purpose) is unchanged.

Why: Your call: history should carry over between Shop Sketch and FreeCAD. Tested: a length edited in FreeCAD shows on reopen, through components and mirrors.
