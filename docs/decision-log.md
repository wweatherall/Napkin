# Shop Sketch decision log

This file is the decision log (P09): Decisions (Active and Tentative), Superseded decisions, Open questions,
Work list, Tunables, then Details (the full text of long decisions). Edit it here, in the same commit as the change
it records. Search it by ID (`grep "^| I34 "`; a row ending "(Details below.)" has its full text at `### I34`)
rather than reading it whole. Keep a table row short: one or two sentences of decision, the reason in a line;
longer text (measurements, tests, edge cases) goes in a `### <ID>` section under Details. Tables and Details stay
sorted by ID (the pre-commit hook runs tools/sort_decision_log.py; its --check also matches rows to sections). Before 2026-11-21 it was a claude.ai Sheet
(revision 83 was the last); git history has every earlier export.

Rule P01: a new decision that contradicts an old one gets a new row naming the old ID; the old row is marked Superseded and moves to Superseded decisions, never deleted. Ask William before countermanding an Active decision.

### I26b
