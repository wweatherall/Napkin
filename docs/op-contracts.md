# Op Contract Pilot (`circle`, H189)

Pilot report for William's decision on whether to extend per-op `CONTRACT` dicts to the remaining 18 ops and/or enforce them at runtime.

## 1. Contract shape

`worker/circle.py` defines a plain dict literal `CONTRACT` beside `CircleActions.op_circle`:

```python
CONTRACT = {
    "type": "circle",
    "fields": {
        "plane": {"required": True, "kind": "Plane"},
        "radius": {"required": True, "kind": "number", "min": 0.001},
        "center": {"required": False, "kind": "[number, number]", "default": [0, 0]},
    },
    "refers_to": ["plane.on.body"],
    "creates": ["id"],
    "tool": "viewport/tools/circle_tool.gd",
}
```

`worker/op_contracts.py` discovers every `*Actions` module (same AST scan as `Model.action_mixins()`), collects its `CONTRACT`, and writes `tests/op_contracts.json` (`--check` exits 1 if missing or stale). No adjustments to the proposed `circle` dict were needed: `op_circle` reads `id`, `plane`, `radius` (`>= TOL = 0.001`), and `center` (default `[0, 0]`), and creates `RectId=id`.

## 3. Adding a field to Circle: files touched

- **Before**: `worker/circle.py`, `docs/protocol.md`, `viewport/tools/circle_tool.gd` (plus `worker/session.py` / `viewport/document.gd` if the field is an ID or ref, and `worker/test_*.py` / `viewport/test_*.gd`). ## 4. Mutation check results

Each defect was introduced in turn, `tests/op_contracts.json` regenerated where applicable, all three checks run, and the change reverted:

1. **Rename `radius` to `rad` in `CONTRACT`**: caught by `worker/test_op_contracts.py` (`KeyError('radius')` on required-only op) and `tools/protocol_map.py --check` (`missing ['rad'], extra ['radius']`).
2. **Drop `refers_to` from `CONTRACT`**: caught by `viewport/test_document.gd` (`_op_refs matches contract.refers_to for circle` failed).
3. **Add unread optional field `color` to `CONTRACT`**: caught by `worker/test_op_contracts.py` (`full op reads exact contract fields` failed) and `tools/protocol_map.py --check` (`missing ['color?']`).
4. **Change `min` from `0.001` to `1.0` in `CONTRACT`**: caught by `worker/test_op_contracts.py` (`radius < 1.0 (min) is rejected` failed).
5. **Remove `center` from `docs/protocol.md` `circle` row**: caught by `tools/protocol_map.py --check` (`missing ['center?']`).

Gaps (ops left out, for H193 + H194):
- **`mirror`** (`worker/mirror.py:op_mirror`): left out of H192 because `group` (and `new_ids` / `creates`) depend on `replace` (`replace=False` copy mode reads `group` and creates `new_ids`/`group`; `replace=True` flip-in-place mode short-circuits `group` unread and reuses target `BodyId`s).
- **`move`**, **`push_pull`**, **`property_edit`**, **`fit`**: ops with modes or conditional field sets (proposal: [op-contracts-with-modes.md](proposals/op-contracts-with-modes.md)).
- Runtime validation against `CONTRACT` in handlers is deferred to H194.

## 5. What Move and Push/Pull contracts would need

**Move (`worker/move.py:op_move`)**: `op_move` has three dispatch modes (`cut`, `selection`, and normal/copy move) with conditional field sets: when `cut` is set, `move_cut` reads `cut` (`{body, op}`) instead of `targets` (which `move_tool` sends as `[]`, currently exempted by `UNREAD_WHEN` in `worker/field_audit.py`); `copy`, `count`, `divide`, `detach`, `new_ids`, and `groups` (`{old: new | [new, ...]}`) are conditional on copying or arrays. A contract for `move` would need per-mode or conditional field rules (`when`/`unless`), list/dict-valued `creates` (`new_ids`, `groups` values) rather than single scalar keys, and conditional `refers_to` across `targets`, `cut.body`, `cut.op`, and `groups` keys.

**Push/Pull (`worker/push.py:op_push_pull`)**: `op_push_pull` takes a tagged-union `target` (`{rect}`, `{face}`, `{region}`, or `face`/`rect` paired with `region`) and optional mode flags (`body`, `assembly`, `through`, `resize_stock`, `edge_fit`, `to_face`) with mutual-exclusion rules (e.g. `to_face` is rejected if `distance >= 0`, `through`, `edge_fit`, `resize_stock`, or `body` is set, or `not on`). Its `distance` constraint is nonzero (`abs(d) >= 0.001`) rather than a positive `min`, its `creates` (`id` plus optional `body`) is conditional, and its `refers_to` depends on which `target` variant and optional `edge_fit`/`assembly` fields are present.
